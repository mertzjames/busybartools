# Christmas Day

Christmas scenes with a festive clock and date between them

## Install

Download `busybartools.christmas-<version>.tgz` from this app's GitHub Release and upload it to your bar.
See [Installing apps](../../docs/INSTALLING.md).

## Develop

```bash
tools/check.sh christmas-day     # build + typecheck (+ tests/check.sh if present)
tools/deploy.sh christmas-day    # install and launch on the bar in .env
tools/release.sh christmas-day   # (maintainers, on main) tag a release; CI publishes it
```

Design notes and decisions: [docs/DECISIONS.md](docs/DECISIONS.md).
