# New Years Eve

Party scenes, a countdown to midnight, and a celebration when the new year rings in

## Install

Download `busybartools.newyear-<version>.tgz` from this app's GitHub Release and upload it to your bar.
See [Installing apps](../../docs/INSTALLING.md).

## Develop

```bash
tools/check.sh new-years-eve     # build + typecheck (+ tests/check.sh if present)
tools/deploy.sh new-years-eve    # install and launch on the bar in .env
tools/release.sh new-years-eve   # (maintainers, on main) tag a release; CI publishes it
```

Design notes and decisions: [docs/DECISIONS.md](docs/DECISIONS.md).
