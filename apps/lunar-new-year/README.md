# Lunar New Year

Lunar New Year scenes, the zodiac animal of the year, and a countdown to the festival

## Install

Download `busybartools.lunarnewyear-<version>.tgz` from this app's GitHub Release and upload it to your bar.
See [Installing apps](../../docs/INSTALLING.md).

## Develop

```bash
tools/check.sh lunar-new-year     # build + typecheck (+ tests/check.sh if present)
tools/deploy.sh lunar-new-year    # install and launch on the bar in .env
tools/release.sh lunar-new-year   # (maintainers, on main) tag a release; CI publishes it
```

Design notes and decisions: [docs/DECISIONS.md](docs/DECISIONS.md).
