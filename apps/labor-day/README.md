# Labor Day

A tribute to American workers that opens into the end of summer: raising steel, a parade of trades, the harvest, a cookout, a beach sunset and fireworks

## Install

Download `busybartools.laborday-<version>.tgz` from this app's GitHub Release and upload it to your bar.
See [Installing apps](../../docs/INSTALLING.md).

## Develop

```bash
tools/check.sh labor-day     # build + typecheck (+ tests/check.sh if present)
tools/deploy.sh labor-day    # install and launch on the bar in .env
tools/release.sh labor-day   # (maintainers, on main) tag a release; CI publishes it
```

Design notes and decisions: [docs/DECISIONS.md](docs/DECISIONS.md).
