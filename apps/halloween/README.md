# Halloween

Spooky-fun Halloween scenes: jack-o'-lanterns, bats, a witch, ghosts and a black cat, with a countdown

## Install

Download `busybartools.halloween-<version>.tgz` from this app's GitHub Release and upload it to your bar.
See [Installing apps](../../docs/INSTALLING.md).

## Develop

```bash
tools/check.sh halloween     # build + typecheck (+ tests/check.sh if present)
tools/deploy.sh halloween    # install and launch on the bar in .env
tools/release.sh halloween   # (maintainers, on main) tag a release; CI publishes it
```

Design notes and decisions: [docs/DECISIONS.md](docs/DECISIONS.md).
