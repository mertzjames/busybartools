# Valentine's Day

Sweet Valentine's scenes: hearts, a cherub, lovebirds, chocolates and a rose, with a countdown

## Install

Download `busybartools.valentines-<version>.tgz` from this app's GitHub Release and upload it to your bar.
See [Installing apps](../../docs/INSTALLING.md).

## Develop

```bash
tools/check.sh valentines-day     # build + typecheck (+ tests/check.sh if present)
tools/deploy.sh valentines-day    # install and launch on the bar in .env
tools/release.sh valentines-day   # (maintainers, on main) tag a release; CI publishes it
```

Design notes and decisions: [docs/DECISIONS.md](docs/DECISIONS.md).
